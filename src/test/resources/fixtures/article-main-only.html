Cursor 2.4

Cursor 2.4 replaces the inline diff view with a side-by-side view for edits that touch more than forty lines. The old view is still available behind a setting, and the team says it will stay there until the next major release.

Indexing was rewritten to run incrementally. On a repository of roughly two hundred thousand files the first index still takes several minutes, but subsequent opens now finish in under a second because only changed files are re-embedded.
