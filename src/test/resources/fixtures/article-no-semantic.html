OpenAI publishes a smaller reasoning model

OpenAI published a smaller reasoning model this morning, positioned between the mini tier and the full model. The company says it matches the larger model on structured extraction while costing about a fifth as much per million output tokens.

The model is available through the same Chat Completions endpoint, so existing integrations only need to change the model identifier. Structured output and function calling are both supported from launch, which was not true of the previous mini release.

Rate limits start lower than the existing tiers and are raised automatically after a week of usage. The documentation notes that the context window is unchanged.
