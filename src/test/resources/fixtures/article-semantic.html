Anthropic ships Claude Code 2.2

Anthropic released Claude Code 2.2 today, adding a persistent session store that survives a terminal restart. The release notes describe the store as opt-in for the first two minor versions, after which it becomes the default for every new project directory.

The release also changes how the agent handles long-running shell commands. Instead of blocking the conversation, commands can now be detached and reported back when they exit, which the team says removes the most common reason for an interrupted session.

Pricing is unchanged. The team says the persistent store is written to the local filesystem only and is never uploaded, which answers the question that dominated the discussion thread.
