# PRD: AI News Digest

## 목표
개발자가 알아두면 좋은 AI 소식 3~5건을 매일 오전 7시 30분(KST) 텔레그램으로 한글 요약해 발송한다.

## 사용자
- **주 사용자**: AI 코딩 도구를 실제로 쓰는 개발자. 매일 쏟아지는 AI 뉴스를 다 볼 시간은 없지만 자기가 쓰는 도구가 바뀌면 바로 알고 싶은 사람
- **부 사용자**: 프로젝트 소유자 본인 (실사용 + 이직 포트폴리오)

### 관심 주제 우선순위
1. AI 코딩 도구 (Claude Code, Codex, Cursor 등)
2. 모델 릴리즈 / API 변경
3. AI 산업 · 트렌드

## 핵심 기능
1. **구독** — 랜딩페이지의 구독 버튼이 텔레그램 딥링크(`https://t.me/<bot>?start=web`)로 연결된다. 사용자가 봇에게 `/start`를 보내면 `chat_id`를 저장하고 환영 메시지와 최근 다이제스트를 즉시 보낸다. `/stop`으로 해지, `/help`로 안내
2. **생성** — 매일 07:00에 여러 소스에서 후보 기사를 수집하고, LLM이 1~5점으로 채점해 상위 건을 선별한 뒤, 본문을 크롤링해 한글 제목과 요약을 생성한다
3. **발송** — 매일 07:30에 활성 구독자 전원에게 발송한다(주말 포함). 발송 이력과 결과를 저장하고, 아카이브 웹페이지에서 지난 다이제스트를 조회할 수 있다

## 발송 규칙
- 시각: 매일 07:30 KST (주말·공휴일 포함)
- 건수: 3~5건. 채택 기준(LLM 3점 이상)을 넘는 게 적으면 1~2건도 허용
- 0건이면 `오늘의 AI 뉴스는 없습니다.` 메시지를 발송한다 (침묵하지 않는다)
- 언어: 한글. 영문 출처는 한글로 번역·요약한다
- 건별 포맷: 한글 제목 + 한글 요약 3~4문장(최대 600자) + 출처 도메인 하이퍼링크
- 전체 메시지는 항상 4,000자 이하를 유지한다

## 제약
- 운영 예산: 월 5,000원 이하 (현재 설계 기준 약 1,850원)
- 인프라: Oracle Cloud Always Free (ARM64)

## MVP 제외 사항
- 사용자별 관심 키워드 개인화 구독 (전원 동일한 다이제스트를 받는다)
- 관리자 웹 페이지 및 Spring Security
- 이메일·Slack·Discord 등 텔레그램 외 발송 채널, RSS 피드 출력
- 탈락한 후보 기사 전량 저장 (선별 튜닝용 데이터셋)
- 자동 배포(CD). 배포는 서버에서 수동 실행한다
- HN 댓글 여론을 요약에 반영하는 기능
- 다국어 지원

## 디자인
- 다크모드 고정. 마케팅 랜딩이 아니라 매일 쓰는 도구처럼 보여야 한다
- 무채색 기반 + 포인트 컬러 1가지. **보라/인디고 계열 금지** (AI 클리셰)
- 랜딩 첫 화면에 실제 발송된 다이제스트를 바로 노출한다. 설명보다 실물을 먼저 보여준다
- 상세 규칙은 `docs/UI_GUIDE.md` 참조
